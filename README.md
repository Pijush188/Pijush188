## 🛰️ What I build at work

<table>
  <tr>
    <td width="33%" valign="top">
      <h3>🔗 Alarm Correlation Engine</h3>
      <sub><b>Knowledge graph · RCA</b></sub>
      <p>Groups hundreds of downstream network alarms into incidents and names the root cause with a <b>deterministic, explainable 0–1 confidence</b> — using reverse BFS, LCA, blast radius and weighted Dijkstra over a topology graph, plus a ChromaDB + BM25 memory of past incidents.</p>

      <sub><b>Vision LLM → graph</b></sub>

    </td>
