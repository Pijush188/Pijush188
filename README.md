## About

I'm a Junior Data Scientist at Calsoft in Kolkata. I joined as an AI/ML intern in February 2025 and moved into a full-time role in September 2025, after completing my B.Tech in Information Technology at Meghnad Saha Institute of Technology.

Most of my work sits between large language models and structured data. I build systems that convert engineering drawings into queryable graphs, trace the root cause of network failures across a topology, and support assistants that keep conversation context and can reverse their own changes. Day to day, that means working with LangGraph, retrieval pipelines, Neo4j, NetworkX and FastAPI, and evaluating LLM behaviour with LangSmith and DeepEval.

Outside work, I build deep learning and frontend projects, several of which are live below.

## Work highlights

**Alarm Correlation Engine** · Knowledge graphs, root-cause analysis
Groups large bursts of downstream network alarms into incidents and identifies the likely root cause with a deterministic, explainable confidence score. The approach uses graph traversal (reverse BFS, lowest common ancestor, weighted Dijkstra) over a network topology, backed by a ChromaDB and BM25 knowledge base of previously resolved incidents.

**P&ID Diagram Intelligence** · Vision models, Neo4j
Extracts equipment and connections from engineering drawings using a vision model and stores them in a graph, so engineers can query a diagram in natural language or Cypher.

**Test-Data AI Assistant** · LLM applications, hybrid retrieval
A conversational assistant with session memory and rollback support, built on a vector knowledge base with hybrid search.
